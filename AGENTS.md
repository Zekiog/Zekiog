## For AI Agents Working on This Repository

### ✅ You May

- Update `README.md` to reflect current projects, stack, or status
- Fix broken links or outdated badge URLs
- Update the "Building Now" table
- Correct spelling or grammar
- Improve visual formatting and badge layout

### 🚫 You Must NOT

- Change contact information (email, social handles, Upwork link) without explicit human approval
- Add unverified project links — every repo link must actually exist
- Add skills, certifications, or credentials that have not been confirmed by the owner
- Change the operating principles or security policy section without approval
- Push directly to `main` — always open a PR

### 📋 Pull Request Requirements

- One focused change per PR
- Title format: `type(scope): short description` (e.g., `docs(readme): update building-now table`)
- Describe what changed and why
- Check that all links resolve before opening the PR
